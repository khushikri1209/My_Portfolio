# My_Portfolio
Personal portfolio website of Khushi Kumari, a MERN Stack Developer. Built with React and Vite, with projects, skills, experience and a contact form.

## Git Setup

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/khushikri1209/khushi-portfolio.git
git push -u origin main
```
